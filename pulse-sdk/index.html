Pulse SDK

AI Agent Governance Middleware for ASEAN

Install

$ pip install pulse-sdk

Quickstart

from pulse_sdk import PulseGuard

guard = PulseGuard("https://your-pulse-host", agent_id="my-agent")
@guard.watch()
def run_agent(prompt): return call_llm(prompt)

Methods

Method Description
.watch() Decorator that wraps any function and sends its input/output to Pulse for governance review after each call.
.intercept() Manually report input and output text to the Pulse backend. Raises PulseCircuitTrippedException when the circuit breaker blocks the call.
.new_session() Creates a new session UUID and attaches it to subsequent intercept calls for traceability.
.get_status() Calls GET /health on the Pulse backend and returns the service status payload.

What is Pulse

Pulse is middleware that monitors AI agent behaviour in real time, scoring inputs and outputs against governance policies as your agents run. It detects behavioural drift and anomalies, then trips a circuit breaker to halt unsafe traffic before it reaches production systems.
